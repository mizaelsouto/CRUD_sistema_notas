Repositório base da avaliação prática de desenvolvimento de um **Sistema CRUD (Create, Read, Update, Delete) para Gerenciamento de Notas Escolares**.

---

## 🎯 Requisitos Funcionais da Atividade

1. **Cadastro de Alunos e Disciplinas (`Create`):** Registro de matrícula, nome do aluno e avaliações.
2. **Consulta de Boletim e Médias (`Read`):** Listagem de notas por turma/aluno com cálculo automático de média e status (*Aprovado*, *Recuperação* ou *Reprovado*).
3. **Atualização de Notas (`Update`):** Correção de lançamentos e registro de recuperação.
4. **Exclusão de Registros (`Delete`):** Remoção segura com confirmação.
